# Результаты проверки — 25 октября 2026

## Подтверждено

- Среда проверки: Linux, Node.js 24.19.0, npm 11.9.0.
- `npm ci` — успешно. Сторонних зависимостей нет.
- `npm run check` — успешно.
- `npm test` — **38 тестов пройдены**, 0 ошибок, 0 пропусков.
- Проверяются поиск по категории/зоне, альтернативные поля контактов, объединение дублей с сохранением источников, сохранность филиалов, CSV/BOM/формулы, кэш, ошибки HTTP/JSON, частичные результаты, ограничение частоты, Retry-After, блокировка параллельного запуска и CLI.
- Отдельный интеграционный тест выполняет настоящий HTTP POST к локальному тестовому серверу. Данные тестов синтетические, не реальные организации.
- `npm start -- --cities Тверь --target 5` действительно выполнен через рабочий CLI с настоящим адресом Overpass. Завершился с кодом **2**, статусом **failed**, причиной **NETWORK**. Записаны CSV с заголовками и отчёт об ошибке; фиктивных результатов нет.
- Независимая проверка HTTPS установила причину: прокси облачной среды возвращает **403 CONNECT** для `overpass-api.de`. Соединение не достигает Overpass.
- Исходные репозитории `igor-sites-portfolio` и `hair-salon-site` остались без изменений, на прежних SHA.

## Ещё не подтверждено

- Получение реальных организаций из Overpass: **заблокировано сетью этой среды**. Нельзя считать результатом 0 реально найденных компаний: сам запрос не выполнен сервером.
- Актуальность полей в реальном ответе, размер выборки и число подходящих организаций в каждом городе.
- Запуск непосредственно на Windows 11: здесь доступен Linux. Для Windows подготовлены `start.cmd`, команда `npm.cmd start`, переносимые пути и UTF-8 CSV. Нативный запуск нужно проверить на компьютере Игоря.
- Аудит сайтов и генерация предложений относятся к следующему этапу; в версии 0.1 их нет.

## Продолжение

Небольшое испытание на Windows с Node.js 24 LTS: `npm.cmd start -- --cities Тверь --target 5`. Затем проверить `README.txt` и `report.json` в новой папке outputs. При успешном ответе полный поиск: `npm.cmd start`.

Для испытания в облачной среде в черновик её конфигурации добавлен домен `overpass-api.de`, прежние разрешения сохранены. Также сохранены инструкции запуска этого проекта. Черновик требует сохранения/публикации пользователем; он сам не меняет действующие сетевые правила. Обход блокировки не выполнялся.

В текущем состоянии исходники существуют локально; отдельный репозиторий GitHub для этого проекта не создан и загрузка туда не выполнялась.
